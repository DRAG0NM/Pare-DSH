# Pare-DSH 设计稿

> 状态：宿主接入方案草案，尚未验证 DSH SDK 或实现插件。

## 1. 目标

Pare-DSH 将 Pare Core 的本地扫描与计划能力封装为 Agent 工具，使 Agent 能读取占用摘要、生成供用户审阅的计划，并解释计划证据。插件不负责识别垃圾文件，不维护第二份规则库，也不直接访问目标文件系统。

DSH 宿主的 SDK、工具注册协议、审批 API、权限声明和 sidecar 分发能力尚未取得一手验证。因此本文将“DSH 接入”视为待核实项，不声称任何宿主审批已经闭环。

## 2. 系统边界

```text
DSH host
  └─ pare-dsh adapter
       ├─ validates tool arguments and bounded output
       ├─ starts pinned Pare Core CLI
       ├─ parses versioned JSON responses
       └─ returns summary + local result reference

Pare Core (separate repository and release)
  ├─ scanner
  ├─ rules and probes
  ├─ plan builder
  └─ gated executor
```

插件与核心通过本机子进程和版本化 JSON 交互。首版不引入本地 HTTP 服务、远程账户或后台 daemon。CLI 退出码、schema 版本、超时、取消和标准错误处理在接口测试中固定。

## 3. 工具契约

首版暴露：

| 工具 | 输入 | 输出 | 写入待清理数据 |
|---|---|---|---:|
| `disk_scan` | 卷标识、受限扫描选项 | 摘要、覆盖缺口、报告引用、扫描 ID | 否；会写本地报告 |
| `disk_plan` | 扫描 ID、规则集版本 | 候选数量、风险摘要、计划摘要、plan ID | 否；会写本地计划 |

执行工具在宿主能力确认之前不注册。以后若增加 `disk_apply` 与 `disk_undo`，参数只接受 Pare 签发的 plan/batch ID 和明确的用户选择，不接受任意路径、shell、glob 或规则覆盖项。

工具返回内容限制长度。完整报告保存在本机由 Pare 管理的位置；插件响应给 Agent 的内容以候选数量、总量口径、风险分布、前若干项及不完整原因组成。路径对模型可见前应评估隐私影响并提供摘要化策略。

## 4. 核心程序获取和版本兼容

插件使用 Pare 的固定发布版本，不解析浮动的 `latest`。安装或更新时校验下载来源、版本及 SHA-256；核心版本与插件声明的兼容 schema 不符时，停止调用并提示升级/降级。发布资产不得携带本机扫描数据、日志或用户凭据。

第一版优先采用随插件包附带经验证的 Windows x64 sidecar，或由用户明确选择固定版本下载。最终分发方式取决于 DSH 包限制和仓库许可；不静默下载执行未知版本。

## 5. 审批和威胁边界

读操作可能返回用户名、项目路径和软件清单，插件需要清晰限定扫描范围，并对 agent 返回内容做最小化。插件不会把路径解释成 shell 参数，不拼接未经参数化的数据，不把标准错误中的敏感内容直接返回。

写操作需同时具备：

1. 宿主提供的用户审批信号能绑定具体 Pare 计划摘要、用户选择、动作与有效期。
2. Pare Core 在执行前重验文件身份、路径父链、计划状态、规则版本和保护范围。
3. 插件只接受受控 ID，不允许模型把其他路径或命令塞入参数。
4. 每次执行有可审计结果；失败、中断和审批无法验证时拒绝继续。

未验证这些条件前，写工具保持关闭。插件不代替 Pare executor，也不通过 prompt 约束冒充权限隔离。

## 6. 失败处理

- 核心不存在、摘要不匹配、版本不支持：不执行，返回安装或版本错误。
- 超时或取消：终止核心进程，报告任务未完成；不把部分结果当完整扫描。
- JSON 非法、schema 不支持或退出码表示部分失败：标记不完整并保留诊断引用。
- DSH 审批状态缺失或不明确：拒绝写操作。
- 输出超过限制：截断展示摘要并保留本地报告引用，不丢弃错误状态。

## 7. 验收标准

- 插件只调用固定的核心命令和结构化参数，不执行通用 shell 字符串。
- 扫描/计划工具在没有管理员权限和无网络环境下能按 Pare 能力工作。
- 版本不匹配、摘要错误、超时、取消、非法 JSON 和部分扫描均显示为失败或不完整。
- 扫描范围及路径暴露情况在工具说明和响应中可见。
- 写工具默认不存在；只有宿主审批合同通过测试后，才能单独设计和评审写工具。
